# Security reporting

Please report vulnerabilities privately to the maintainer at deolsugam@gmail.com. Use a synthetic fixture and explain the field that escaped minimization. Do not attach live credentials or personal captures. No response SLA is promised.

Harborstrip minimizes known metadata by rebuilding the output. It is not a guarantee of anonymity or a replay fixture generator. Endpoint mode preserves host/path. Review before sharing. See docs/SECURITY.md for review results and accepted risks.
