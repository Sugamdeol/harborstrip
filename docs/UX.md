Strict aliases remain available; the CLI retains its strict default. After import, outgoing manifest shows real retained-request and removal counts. Request sequence carries status and duration; search and failure filter reduce review work. Save clean HAR is primary; offline report/Markdown/receipt are real secondary downloads.

File reading uses revision guard so stale read cannot replace a newer packet or clear action.

Keyboard: native input/radio/button/details semantics, skip link and visible focus. No modal traps. Mobile stacks importer/policy above manifest, table scroll is contained, text wraps.
