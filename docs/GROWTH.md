# Distribution hypotheses

Discovery → synthetic demo → see removed fields plus useful failures → export report → recipient sees attribution → tries own capture. No file-sharing server or invitation spam.

| Channel | Audience / presentation | Avoid |
|---|---|---|
| Show HN | Developers; live demo, privacy contract and limitations | Landing-only launch, star claims |
| GitHub | Support/QA engineers; canary tests and one-command CLI | Fake badges or guarantee of safety |
| Niche Reddit | Ask for usability feedback with synthetic before/after | Unsolicited repeated promotion |
| Dev.to/tutorial | HAR fields that should not enter tickets | Invented breach stories |
| Team adoption | One engineer shares a useful report | Collecting recipient emails |

Post drafts only. No posts/emails sent. Ask 5 engineers to compare against current sanitizer before bigger launch. Pause if aliases prevent diagnosis or current tools are equally convenient.
